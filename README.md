# 📊 Análise de Mercado Imobiliário & Oportunidades de Expansão (Airbnb)

Uma análise exploratória e estratégica de dados do Airbnb para identificar **regiões de alta demanda**, **concentração de imóveis de luxo** e **oportunidades de expansão imobiliária**.

---

## 🎯 Objetivo do Projeto

Apoiar investidores e gestores de propriedades a tomar decisões baseadas em dados sobre:
1. Quais bairros possuem alta demanda por imóvel, mas pouca concorrência.
2. Onde estão concentrados os imóveis do segmento *premium*/luxo.
3. Quais regiões apresentam maior vocação imobiliária.
4. Onde estão as melhores oportunidades gerais de expansão.
